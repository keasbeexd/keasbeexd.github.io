# keasbeexd.github.io

Personal site, served by GitHub Pages: the home page, and Cloudroll's page, privacy policy and support page. Plain HTML and CSS with two small scripts, no build step and no libraries: `assets/ide.js` makes the home page's IDE work (menus, windows, F-keys, Make with live GitHub data, a DOS shell, a CRT effect) and `cloudroll/demo.js` drives the phone mockup on the Cloudroll page. Both pages read fine without them.
